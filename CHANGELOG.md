# Changelog

All notable changes to OneMode are documented in this file.

## [0.1.0] - 2026-10-03

### Added

- Initial OneMode UI design system package.
- Namespaced `.om` CSS architecture.
- Theme-aware design tokens.
- Light and dark theme support.
- Responsive application shell.
- Responsive sidebar navigation.
- Application header and breadcrumb layouts.
- Page layout utilities.
- Buttons and button states.
- Cards.
- Badges.
- Alerts and validation states.
- Dropdowns.
- Modals.
- Tabs.
- Pagination.
- Progress indicators.
- Skeleton loading states.
- Toast notifications.
- Tooltips.
- Icon utilities.
- Form controls.
- Date and time controls.
- Data tables.
- Utility classes.
- JavaScript behaviors for interactive components.
- Public package entry points for CSS and JavaScript.

### Package Hardening

- Removed accidental self-dependency from the package.
- Restricted package exports to documented public entry points.
- Added package documentation files.
