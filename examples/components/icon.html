Icon Vocabulary

The canonical icon vocabulary for the EkaMod School Enterprise System. Bootstrap Icons provide the glyphs; OneMode provides the usage conventions.

Use the same icon for the same concept throughout EkaMod. This prevents different modules from developing their own visual language.
